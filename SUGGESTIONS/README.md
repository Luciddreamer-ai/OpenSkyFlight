# Suggestions for the iPad product

This folder is the playground talking to the product. Ideas we've
tested or mapped on our fork (Luciddreamer-ai/OpenSkyFlight), written
up clearly for the iPad version (Lucineer/OpenSkyFlight) to consider.

Not pull requests — just "these are cool, think about these." Take
what fits iPad-first, ignore the rest. Each file states the idea, why
it fits iPad specifically, and where it would plug in.

Numbering is chronological, not priority.
